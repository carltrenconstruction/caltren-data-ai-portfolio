# Caltren Construction - Data, BI & AI Portfolio

This repository contains all technical data products, Business Intelligence dashboards (Power BI & Tableau), automated scripts, and AI/ML pipelines developed for Caltren Construction analytics and reporting.

## Directory Overview
- **[Dashboards](./dashboards/)**: Contains Power BI (`.pbix`) layout documentation, templates, and Tableau workbooks.
- **[AI & ML Models](./ai-ml-models/)**: Machine learning scripts, predictive models, and artificial intelligence utilities.
- **[Data Pipelines & SQL](./data-pipelines/)**: Database schemas, migration queries, and data cleaning scripts.
- **[Shared Assets](./shared-assets/)**: Reusable color palettes, themes, and configuration files.
